# OP7TPro SukiSU-Nova Kernel

GitHub Actions builder for a SukiSU-Nova kernel for OnePlus 7T Pro (HD1913, SM8150),
stock OxygenOS 11 (Android 11), kernel 4.14.190.

Source: OnePlusOSS/android_kernel_oneplus_sm8150 @ oneplus/SM8150_R_10.0
Output: AnyKernel3 zip (replaces kernel in boot, keeps vendor/ramdisk).
